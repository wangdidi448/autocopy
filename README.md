# 快捷工作台 autocopy

一个悬浮在 Windows 桌面的快捷信息工作台：把常用信息（姓名、手机号、地址、邮编、密码等）拆成一条条字段，**点一下就自动复制**；支持分组、拖动排序、批量导入导出，还能自动获取邮箱 / 短信验证码。数据全部保存在你自己电脑上，不上传任何服务器。

> 本教程默认你完全没接触过编程，按顺序一步步操作即可。全程只需要装 **1 个运行环境（Python）** 和 **1 个界面库（PySide6）**。

---

## 一、它能做什么

- 无边框圆角悬浮窗：可拖动、置顶、折叠，不挡视线
- 字段**点击即复制**；字段名（key）可改名（组内自动查重）、换颜色、加粗
- 一键隐藏 / 显示所有内容（value），公共场合只显示字段名
- 分组管理：如「求职信息」「应用密码」，可新建 / 改名 / 删除（删除前都有确认弹窗）
- 条目**按住拖动**即可调整先后顺序
- **批量导入 / 导出 JSON**：换电脑不用重新录入
- 邮箱验证码：绑定后自动识别新邮件里的验证码并复制（适配 163 / 126 / QQ / Gmail / Outlook 等）
- 短信验证码：安卓手机插 USB 即可读取新短信验证码（ADB 可在软件内一键下载）

## 二、安装 Python（已安装可直接跳到第三章）

程序是用 Python 写的，电脑里需要先有 Python 运行环境，**只需装一次**。

### 1. 下载
浏览器打开官网：<https://www.python.org/downloads/>
点页面上黄色的 **Download Python 3.x.x** 按钮，等待安装包下载完成。

### 2. 安装（关键一步，别点太快）
双击下载好的安装包，在安装界面**最下方先勾选 `Add python.exe to PATH`**（把 Python 加入环境变量，不然后面会报"不是内部命令"），然后再点 **Install Now** 等待安装完成，点 Close。

### 3. 验证是否成功
按 `Win + R`，输入 `cmd` 后回车，会弹出一个黑色命令窗口，在里面输入下面这行并回车：

```bash
python --version
```

如果显示 `Python 3.11.x`（或更高版本号），就说明装好了。
如果提示 `'python' 不是内部或外部命令`，说明第 2 步的 PATH 没勾选——重新运行安装包，选到勾选后再装一次即可。

## 三、获取本程序

### 方式 A：直接下载 ZIP（推荐新手）
1. 打开本项目页面 <https://github.com/wangdidi448/autocopy>
2. 点绿色的 **Code** 按钮 → **Download ZIP**
3. 把 ZIP 解压到一个**固定文件夹**，例如 `D:\autocopy`（不建议一直放在"下载"里，之后也别随意移动，路径尽量不含特殊符号）

### 方式 B：用 Git 克隆（会用 git 的话）

```bash
git clone https://github.com/wangdidi448/autocopy.git
```

## 四、安装依赖库（只有一个：PySide6）

界面基于 PySide6（Qt），需要联网安装一次。

**在程序文件夹里打开命令行**：进入刚才解压出的文件夹，点一下顶部的地址栏，把内容删掉、输入 `cmd` 后回车，弹出的黑窗口就已经定位在当前目录了。然后输入：

```bash
pip install PySide6
```

等待进度条走完、看到 `Successfully installed PySide6-...` 即成功。

> 如果下载很慢或中途红色超时，改用国内清华镜像（二选一执行即可）：

```bash
pip install PySide6 -i https://pypi.tuna.tsinghua.edu.cn/simple
```

验证是否装好（输出版本号即成功）：

```bash
python -c "import PySide6; print(PySide6.__version__)"
```

## 五、启动程序

- **方式 1（推荐日常使用）**：直接双击文件夹里的 `启动快捷复制.bat`，不会出现黑色控制台窗口。
- **方式 2（排查问题时用）**：在命令行输入下面命令启动，若有报错会直接打印在窗口里，方便定位：

```bash
python qt_workdesk.py
```

首次启动后，程序会在同一文件夹自动生成两个数据文件：

| 文件 | 作用 |
|---|---|
| `quick_copy_data.json` | 你的全部字段 / 分组数据 |
| `verify_config.json` | 邮箱 / 手机绑定信息（授权码经 Windows DPAPI 加密） |

## 六、新手使用指引

1. **添加条目**：点标题栏 `＋`，填写字段名（如"姓名"）和内容（如"张三"），可同时设置 key 颜色 / 加粗，确定即可。
2. **复制**：鼠标点一下对应条目行，内容就进剪贴板了，直接去别处 `Ctrl+V` 粘贴。
3. **改 / 删**：每行右侧 `✎` 修改、`✕` 删除（删除前会弹窗确认）。
4. **调整顺序**：按住某一行上下拖动，松手即插入到目标位置。
5. **建分组**：标题栏下方下拉框旁边的 `＋` 新建组、`✎` 改名、`✕` 删除整组。
6. **隐藏内容**：标题栏点 `隐`，所有内容变成 `••••••` 只显示字段名；再点 `显` 恢复。
7. **换机迁移**：旧电脑点分组栏 `⇑` 导出 JSON → 拷到新电脑 → 新电脑点 `⇓` 选这个文件导入（可选替换或合并），无需重录。

## 七、验证码功能怎么配置

### 1. 邮箱验证码（以 163 邮箱为例）
需要的是 **IMAP 授权码，不是邮箱登录密码**：

1. 浏览器登录 163 邮箱网页版 → **设置 → POP3/SMTP/IMAP**
2. 开启 **IMAP/SMTP 服务**，按提示用手机发短信验证，得到一串**授权码**
3. 回到本软件，点验证码区域的 **绑定**，填写邮箱地址、粘贴授权码、IMAP 服务器（输入邮箱后会自动带出），点 **保存并绑定邮箱**
4. 之后需要验证码时点 **邮箱**：软件会扫描新邮件、自动识别验证码并复制，点验证码数字本身也可再次复制

> QQ 邮箱流程类似：设置 → 账户 → 开启 IMAP → 生成授权码。

### 2. 短信验证码（安卓手机）
1. 手机 **设置 → 关于手机 → 连续点 7 次"版本号"**，开启"开发者模式"
2. 返回设置进入 **开发者选项**，打开 **USB 调试**
3. 用数据线把手机连到电脑，手机弹窗点 **允许 USB 调试**
4. 软件内点 **绑定 → 下载adb**（会自动下载安装，只需一次）→ 点 **检测** 看到设备 → 点 **绑定设备**
5. 需要短信验证码时点 **短信** 即可

## 八、常见问题 FAQ

**Q：双击 `启动快捷复制.bat` 一闪而过？**
A：说明启动报错了。改用第五章"方式 2"在命令行里运行，红色报错最后一行就是原因；常见是 Python 没装 / PySide6 没装，按第二、四章补装。

**Q：提示 `'python' 或 'pip' 不是内部或外部命令`？**
A：安装 Python 时没勾选 `Add python.exe to PATH`，重装勾选即可。

**Q：`pip install` 下载特别慢或报红色超时？**
A：用第四章的清华镜像命令安装。

**Q：窗口被我拖到屏幕边缘找不到了？**
A：删掉程序文件夹里的 `quick_copy_data.json` 再启动会恢复默认位置（注意：这会清空已录入字段，也可以先打开该 json 找到 `"pos"` 改成 `[100, 100]` 保存）。

**Q：杀毒软件 / Windows 弹出安全提示？**
A：本软件完全开源、本地运行，不联网上传数据；如被拦截选择"允许/信任"即可。邮箱功能仅在你主动点击时连接对应邮箱服务器。

## 九、程序文件说明

| 文件 | 说明 |
|---|---|
| `qt_workdesk.py` | **主程序（PySide6 / Qt 版，推荐使用）** |
| `quick_copy_widget.py` | 早期 tkinter 版本，保留备份，不影响使用 |
| `启动快捷复制.bat` | Windows 双击启动器（无控制台） |
| `quick_copy_data.json` | 运行后自动生成：你的字段数据 |
| `verify_config.json` | 运行后自动生成：验证码绑定配置 |
| `adb/` | 使用短信功能时自动下载，无需手动安装 |
